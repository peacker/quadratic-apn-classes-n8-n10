# Database of known classes of quadratic APN functions (n = 8, 10)

This repository lists the known classes of quadratic APN functions in dimensions 8 and 10. For each class it
gives a class key, the value M defined below, and the result of a test for CCZ-equivalence to a permutation (the
"big APN problem"). For n = 8 it also gives the works whose lists contain the class.

For quadratic APN functions, CCZ-equivalence and EA-equivalence coincide (Yoshiara, 2012), so "class" means
either.

## Summary

| | n = 8 | n = 10 |
|---|---|---|
| known classes | 5,813,648 | 29 |
| CCZ-equivalent to a permutation | none | none |
| classes with M = 2 / 3 / 4 / 5 | 209 / 5,792,104 / 21,335 / 0 | 0 / 7 / 15 / 7 |
| files | `n8/classes/`, `n8/luts/` | `n10/quadratic_classes.tsv` |

## Layout

| path | content |
|---|---|
| `n8/classes/part_X.tsv` | one line per class, split by the first hex digit X of the key: `inv M status sources` |
| `n8/luts/XX.tsv` | a lookup table for every class with source `bellini26`, split by the first two hex digits XX of the key: `inv lut`. The other classes are omitted because their sources already publish a function of each class, as a lookup table, a polynomial or another compact form (see the sources below) |
| `n8/report.md` | number of classes per source, and number found in no other source |
| `n8/source_checksums.txt` | SHA-256 of every source file as downloaded or converted |
| `n10/quadratic_classes.tsv` | one line per class, with a lookup table: `name inv M status lut` |
| `tools/` | the scripts that computed the keys and the tests |

## Columns

- `inv`: the class key, the first 16 hex digits of SHA-1 of `repr(ortho_invariant(F, n))`. Here
  `ortho_invariant` (in `tools/lib/apnsearch/invariants.py`) is the pair (differential spectrum, extended Walsh
  spectrum) of the ortho-derivative of F. For quadratic APN functions this is a CCZ-invariant, so **different
  keys prove that two functions are inequivalent**. Equal keys do not prove equivalence, but within every
  source all keys are distinct.
- `M`: the largest dimension of a linear subspace contained in NB_F ∪ {0}, where NB_F is the set of non-bent
  components.
- `status`: `none` means not CCZ-equivalent to a permutation. The test is the counting criterion (M < n/2,
  Göloğlu–Pavlů) and otherwise the exact dual test of [Bellini, ePrint 2026/2800](https://eprint.iacr.org/2026/2800).
- `sources` (n = 8): the works whose lists contain a function of the class (keys below).
- `name` (n = 10): the family or instance of the class (see below).
- `lut`: the lookup table of one function of the class, as 2^n decimal values separated by commas.

A class can have several sources. For example, 4,189 classes of `bellini26` are also in `bgp26` or in
`langevin25`.

Notes:
- The list `sboxu_firstQAM` also contains the Kasami function x^57, which is not quadratic and so is not in
  `n8/classes/`. It is not CCZ-equivalent to a permutation either.
- The 6 classes of `kuznetsov26`, 4 of which were reported as new, have the same keys as functions of Edel–Pott's
  list and of Yu–Wang–Li's list.

## Sources, n = 10

The 25 published classes are those collected in [Bellini, ePrint 2026/2800](https://eprint.iacr.org/2026/2800).
That paper also lists the other published functions that lie in these classes. The names F3, F4, F12
and F13 are those of Kaleyski, *Invariants for EA- and CCZ-equivalence of APN and AB functions*, Cryptogr. Commun.
13 (2021), Table 3.

| classes | names in the file | work |
|---|---|---|
| 2 | `Gold x^3`, `Gold x^9` | the Gold functions |
| 2 | `F3 ...` | L. Budaghyan, C. Carlet, *Classes of quadratic APN trinomials and hexanomials and related structures*, IEEE TIT 54 (2008) |
| 2 | `F4 ...` | L. Budaghyan, C. Carlet, G. Leander, *Constructing new APN functions from known ones*, FFA 15 (2009) |
| 6 | `F12 ...` | H. Taniguchi, *On some quadratic APN functions*, DCC 87 (2019) |
| 5 | `F13 ...` | L. Budaghyan, T. Helleseth, N. Kaleyski, *A new family of APN quadrinomials*, IEEE TIT 66 (2020) |
| 3 | `Beierle-Leander #1, #3, #5` | C. Beierle, G. Leander, *New instances of quadratic APN functions*, IEEE TIT 68 (2022) |
| 5 | `Budaghyan-Ivkovic-Kaleyski triplicate #1, #3-#6` | L. Budaghyan, M. Ivkovic, N. Kaleyski, *Triplicate functions*, Cryptogr. Commun. 15 (2023), Table 2 |
| 4 | `Bellini 2026, order-5 self-equivalence #1-#4` | E. Bellini, *Quadratic APN functions of F_2^10 with a self-equivalence of prime order*, arXiv:2611.18358, IACR ePrint 2026/2889; data at https://github.com/peacker/apn10-self-equivalences |

Notes:
- The other two instances of Beierle–Leander and the second triplicate instance of Budaghyan–Ivkovic–Kaleyski lie
  in F13 classes.
- The non-quadratic power functions x^57 (Kasami) and x^339 (Dobbertin) are not CCZ-equivalent to permutations
  either. This was decided with `tools/wzs.c` and `tools/run_wzs.py`, which extend the dual test to Walsh
  supports that are not affine. It confirms the computer search of Browning, Dillon, McQuistan and Wolfe (2010),
  as reported by Göloğlu–Langevin (FFA 2020) and Göloğlu–Pavlů (Cryptogr. Commun. 2021).

## Tools

| file | use |
|---|---|
| `testall.py` | key, M and status of every function of a list: `tools/testall.py --n 8 --source NAME --input FILE --out OUT.tsv` (one lookup table per line, any separators) |
| `run_test.sh` | runs `testall.py` on a long list in parallel shards |
| `lib/apnsearch/` | the code behind `testall.py`, a frozen copy of the artifact of ePrint 2026/2800; its C core is compiled on first import |
| `extract_luts.py` | turns the sboxU lists into files with one lookup table per line |
| `decode_bgp26.py` | decodes the database of `bgp26` |
| `taniguchi8.py` | generates the functions of `taniguchi19` |
| `orthokey.c`, `hashkeys.py` | fast keys for the 11.9 million functions of `langevin25` (they agree with `testall.py` on a sample) |
| `wzs.c`, `run_wzs.py` | the test for functions that are not quadratic |

## Adding classes

New classes and new sources are welcome. Please open an issue with the lookup tables, or with a link to them.
